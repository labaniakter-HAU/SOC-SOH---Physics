# Figure and table sources

Every figure in the article and in its Supplementary Materials is drawn by one script in `scripts/`,
and every results table is written by `scripts/revision_make_tables.py`. This file is generated by
`scripts/revision_figure_sources.py`, which runs each script and records the repository files it opens.
Re-running the figure scripts reproduces each figure pixel for pixel. Run every command from the
repository root.
